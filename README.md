# keyboard

This repository aims to document all my keyboards, keyboard configs, and so on.
Here you will find everything from "how to build the keyboard" to the layout to some themes.

---

In the future, I will name my keyboards after something that describes them well.

## Building the keyboard

First, you need a base for the keyboard.
For that, I stick to the [dactyl-manuform](https://github.com/carbonfet/dactyl-manuform) project, as it is my preferred one.

I have also made a fork of carbonfet's dactyl-manuform, though with no changes. So just use the original one.

Then, you need to decide which parts you want to use.
I have decided to use the following parts:

> [!IMPORTANT]
> I don't know if the parts are still available, so I can't guarantee that these Amazon links still work.
> I also don't know if the listed products are available outside the EU. However, you should be able to find similar parts in your region.

> [!NOTE]
> All parts listed here may be EU-only, so be careful.

General supplies you'll always want to have on hand:

- Some copper wire — any cable will do, as it doesn't matter which one you use.
- Soldering iron I use: [amazon](https://www.amazon.de/gp/product/B0GGC5HTT4/ref=ox_sc_saved_title_3?smid=A270SLZCPX6K5L&psc=1)

### My first keyboard

The first custom keyboard I built.

It is a [carbonfet-fork-dactyl-manuform](https://github.com/carbonfet/dactyl-manuform).
The layout is also custom, since I don't follow the default layout (I don't even know what that would look like on this keyboard, if there even is one).

I named it: "First Custom Keyboard".

#### Part list

- The base keyboard [github](https://github.com/carbonfet/dactyl-manuform), printed by myself, though you can also just buy it. For example: [etsy](https://www.etsy.com/de-en/listing/1435804169/dactyl-manuform-mechanical-keyboard-case?lang_mismatch=1)
- RP2040-based boards — I use this one from [amazon](https://www.amazon.de/gp/product/B0H4L5WFRN/ref=ox_sc_act_title_2?smid=A2WSSX5YFMIMA4&psc=1), but any RP2040-based board should work. Remember to buy at least 2, one for each half of the keyboard.
- A TRRS to TRRS cable to connect both halves of the keyboard — I use this one from [amazon](https://www.amazon.de/gp/product/B07FFW8YZR/ref=ox_sc_act_title_5?smid=A36GEU10IX5HPU&psc=1)
- Switches — I use: [amazon](https://www.amazon.de/gp/product/B0D8KB4RPZ/ref=ox_sc_act_title_6?smid=AJJW1W45HAUSR&th=1), which are thocky, MX-compatible, linear, and cheaper than other switches in the thocky category.
- A USB-C to USB-A cable — USB-C to USB-C would also work fine: [amazon](https://www.amazon.de/gp/product/B01GGKYKQM/ref=ewc_pr_img_1?smid=A3JWKAKR8XB7XF&th=1)
- TRRS breakouts — I use: [amazon](https://www.amazon.de/gp/product/B088QXGQTH/ref=ox_sc_act_title_8?smid=A1XDN6LSMACAXM&psc=1)

And lastly, some keycaps — this is where the biggest potential for customization lies.
I use the following keycaps:

- Some white/gray base keycaps in a wide range of sizes, so I can cover as many keys as possible. For my ~71.2% (74 keys) keyboard layout (that's the standard [carbonfet dactyl fork](https://github.com/carbonfet/dactyl-manuform) layout): [amazon](https://www.amazon.de/gp/product/B0BLMJQRSG/ref=ox_sc_act_title_4?smid=A8KICS1PHF7ZO&th=1), XDA keycaps
- For some extra keys, since I know the 1.5u keycaps from the base set aren't enough: [amazon](https://www.amazon.de/gp/product/B0DXDWY463/ref=ox_sc_act_title_5?smid=A111ZR18PX26NO&th=1), black XDA keycaps
- Some extra accent keycaps, 1u, XDA: [amazon](amazon.de/gp/product/B0HFZFYL69/ref=ewc_pr_img_2?smid=A35JIT05N82USV&psc=1)
