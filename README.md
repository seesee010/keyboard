# keyboard

This repository aims to sum up all my keyboard config.
In particular, I use a custom keyboard (see [here](https://github.com/carbonfet/dactyl-manuform))

The layout is also custom as I won't stick to the default layout ( as I even don't know which that would be on that keyboard, lol - if there is even one at all )
So here you will find everything about the keyboard and the layout.
From building the keyboard to the layout itself, everything is documented here.

## Building the keyboard

First, you need a base for the keyboard.
Herefore I stick to the [dactyl-manuform](https://github.com/carbonfet/dactyl-manuform) project as this is my preferred one.

I have also made a fork of the carbonfets dactyl-manuform fork, however with no changes. So just use the original one.

Then, you need to decide which parts you want to use.
I have decided to use following parts:

> [!IMPORTANT]
> I don't know if the parts are still available, so I can't guarantee that this amazon links still work.
> And I also don't know if the listed products are available outside the EU. However you should take some similar parts if you find some in your region.

> [!NOTE]
> All parts here could be EU-only, so be careful.

### My first keyboard

- the base keyboard [dactyl-manuform](https://github.com/carbonfet/dactyl-manuform)
- RP2040 based boards, I take the [amazon](https://www.amazon.de/gp/product/B0H4L5WFRN/ref=ox_sc_act_title_2?smid=A2WSSX5YFMIMA4&psc=1) but every RP2040 based board should work. Remember to buy at least 2 boards, one for each half of the keyboard.
- TRRS to TRRS cable, to connect both halfs of the keyboard together, I take the [amazon](https://www.amazon.de/gp/product/B07FFW8YZR/ref=ox_sc_act_title_5?smid=A36GEU10IX5HPU&psc=1)
- switches, I use: [amazon](https://www.amazon.de/gp/product/B0D8KB4RPZ/ref=ox_sc_act_title_6?smid=AJJW1W45HAUSR&th=1), which are thocky, MX compatible, linear, cheapter than other switches in the thocky category.
- USB-C to USB-A but USB-C to USB-C would also work fine, [amazon](https://www.amazon.de/gp/product/B01GGKYKQM/ref=ewc_pr_img_1?smid=A3JWKAKR8XB7XF&th=1)
- TRRS breakouts, I use: [amazon](https://www.amazon.de/gp/product/B088QXGQTH/ref=ox_sc_act_title_8?smid=A1XDN6LSMACAXM&psc=1)

And at last, some keycaps, here is the biggest potential for customization.
I use following keycaps:

- some white/gray basis keycaps, with a wide range of sizes, so I can at least use as much keys as possible. As for my ~82% keyboard-layout (thats the normal [carbonfet dactyl fork](https://github.com/carbonfet/dactyl-manuform) layout), [amazon](https://www.amazon.de/gp/product/B0BLMJQRSG/ref=ox_sc_act_title_4?smid=A8KICS1PHF7ZO&th=1), XDA keycaps
- For some extra keys, as I know that 1.5u are not enough from the basisc set [amazon](https://www.amazon.de/gp/product/B0DXDWY463/ref=ox_sc_act_title_5?smid=A111ZR18PX26NO&th=1), black, xda keycaps
- some extra hilights, 1u, xda keycaps, [amazon](amazon.de/gp/product/B0HFZFYL69/ref=ewc_pr_img_2?smid=A35JIT05N82USV&psc=1)
